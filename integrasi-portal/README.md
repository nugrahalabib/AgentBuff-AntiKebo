# Bahan integrasi portal AgentBuff

Disiapkan sesi cloud (P13) supaya sesi laptop tinggal memakai saat L2 dan L3
(`docs/05-INTEGRASI-AGENTBUFF.md` §6). Tidak berisi rahasia maupun rincian internal AgentBuff.

| Berkas | Isi | Dipakai di |
|---|---|---|
| `listing.md` | Isian katalog, tagline, deskripsi, kemampuan, tutorial (id/en), tutorial manual | Skrip siapkan produk di repo AgentBuff (L2), terbitkan (L3) |
| `bukti.md` | Draf langkah dan asersi skrip bukti beli dan MCP | Skrip bukti di repo AgentBuff (L3, `GERBANG-RILIS.md` butir 1 dan 8) |
| `../skill/SKILL.md` | Skill pendamping agen | Unggah apa adanya ke listing (satu sumber, tidak disalin ke sini) |

Tautan publik yang dirujuk listing: `/privasi`, `/ketentuan` (halaman tayang tanpa masuk).
